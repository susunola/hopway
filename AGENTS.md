# HopWay UI design

- For full pages with a large unused area below the content, add a section when it gives the user useful information or a relevant action.
- If the page already has the necessary sections, lay them out vertically so the window height shows more of the existing content. Keep related fields aligned and allow scrolling in short windows.
- Fit the content within the page when the available space allows it. Show scrollbars only on axes where content overflows.
- Stretch horizontal control rows across the available content width. Let the main field absorb extra space and align the trailing actions with the content below.
- Check full pages in Simplified Chinese and English at both the regular and minimum window sizes.
